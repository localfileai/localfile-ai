설치 파일 실행

내려받은 설치 파일을 실행하면 앱이 설치됩니다. 문서 분석에 필요한 구성 요소가 설치 파일에 들어 있어, 다른 프로그램을 미리 깔 필요가 없습니다.

첫 실행 — 자동 준비

앱을 처음 켜면 준비가 저절로 시작됩니다. PC 사양에 맞는 AI 모델(약 2.2GB)을 내려받는 동안 진행 상황을 보며 기다리기만 하면 됩니다.

폴더 고르고 사용

자주 묻는 질문

내 문서가 외부로 전송되나요?

아닙니다. 문서를 읽고 분석하는 과정이 전부 사용자 PC 안에서 실행됩니다. 인터넷은 처음 AI 모델을 내려받을 때만 사용하고, 그 뒤로는 오프라인에서도 동작합니다.

왜 처음에 2GB가 넘는 파일을 받아야 하나요?

문서를 이해하는 AI 모델을 사용자 PC에 직접 두기 때문입니다. 외부 서버에 문서를 보내는 방식이라면 다운로드가 필요 없겠지만, 그러면 문서가 PC를 떠나게 됩니다. 한 번만 받으면 이후에는 다시 받지 않습니다.

파일이 엉뚱한 곳으로 옮겨지면 어떡하죠?

앱은 제안만 하고, 사용자가 확인하고 체크한 파일만 실제로 옮깁니다. 옮긴 내역이 기록으로 남아 되돌릴 수 있고, 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 건너뜁니다.

외장 GPU가 없는 내장 그래픽 노트북에서도 쓸 수 있나요?

네. 내장 그래픽이면 충분합니다. 앱이 첫 실행 때 PC 사양을 확인해 그에 맞는 가벼운 모델 구성으로 준비합니다. 검색과 분류는 원래 가벼운 방식으로 동작하므로 성능 차이가 거의 없고, 파일명 추천 속도에서만 차이가 납니다.

설치할 때 Windows 경고가 뜹니다.

코드 서명 인증서가 없는 앱이라 나타나는 안내입니다. 추가 정보를 누른 뒤 실행을 선택하면 설치됩니다. 설치 파일은 이 페이지와 GitHub 릴리스에서만 배포합니다 — 다른 곳에서 받은 파일은 설치하지 마세요.

한글(HWP) 문서도 읽나요?

네. HWP와 HWPX 모두 지원합니다. PDF·DOCX·DOC·PPTX·PPT까지 대학에서 자주 쓰는 형식 7종을 다룹니다.
