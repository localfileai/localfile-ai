# 실험 008: subject에 합쳐진 topic의 보수적 복구

작성일: 2026-08-08

## 지난 코드의 한계

사실 검증은 환각 topic을 제거했지만 LLM이 `인공지능 트랜스포머`를 subject 하나로
반환하면 참 topic `트랜스포머`를 복구하지 못했다.

## 변경 코드를 통한 보완점

알려진 subject 표기 그룹을 접두 앵커로 사용한다. `인공지능_트랜스포머`처럼
subject 뒤에 값이 합쳐져 있고 나머지가 실제 본문에 존재할 때만 이를 topic으로
분리한다. 본문 근거가 없으면 기존처럼 제거한다.

## 실제 결과

입력 JSON:

```json
{"subject":"인공지능 트랜스포머","topic":"","semester":"2026-1"}
```

본문에 두 용어가 있는 경우 최종 결과:

```text
인공지능_트랜스포머_강의자료_2026-1.pdf
```

새 복구 테스트와 전체 회귀 테스트가 통과했다.

## 보완 코드의 한계

현재 앵커는 AI·OS·DB·NETWORK 계열 표기 그룹에 한정된다. LLM이 topic을 전혀
출력하지 않고 subject에도 합치지 않으면 복구하지 못한다. 임베딩 기반 핵심어
추출은 아직 사용하지 않는다.
