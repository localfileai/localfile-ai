# 실험 보고서 유지 지침

이 저장소에서 코드 변경 후 실제 실행 또는 테스트를 수행한 실험을 완료하면,
사용자가 별도로 반복 요청하지 않아도 이 폴더에 순차 보고서를 추가한다.

- `NNN-kebab-case-title.md` 형식과 다음 번호를 사용한다.
- `지난 코드의 한계`, `변경 코드를 통한 보완점`, `그러나 존재하는 한계`를 반드시
  별도 섹션으로 포함한다.
- 변경 파일과 실제 명령, 입력, 출력, 시간, 테스트 수치를 기록한다.
- 추정과 실제 측정 결과를 구분한다.
- 실패도 결과이며 숨기지 않는다.
- `README.md`의 보고서 목록에 새 항목을 추가한다.
