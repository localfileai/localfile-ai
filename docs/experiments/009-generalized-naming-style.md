# 실험 009: 예시 기반 명명 스타일 일반화

작성일: 2026-08-08

## 지난 코드의 한계

사용자 표기 개인화가 AI, OS, DB 등 고정 alias 사전에 제한됐고 모든 파일은
밑줄 구분자를 사용했다.

## 변경 코드를 통한 보완점

유사·승인 예시에서 임의 영문 토큰의 대소문자를 case-insensitive로 찾아 그대로
사용한다. 또한 예시 전체의 `_`와 `-` 수를 비교해 다수 구분자를 선택한다.

## 실제 결과

예시가 `TSN-네트워크-과제-2025.2.pdf`이고 LLM subject가 `tsn`일 때 결과는 다음과
같다.

```text
TSN-스케줄링-강의자료-2026-1.pdf
```

고정 사전에 없는 TSN의 대문자 표기와 하이픈 구분자를 모두 반영했다.

## 보완 코드의 한계

구성요소 순서와 의미 alias 자체를 학습하지는 않는다. 소수의 잘못된 예시가 스타일을
오염시킬 수 있고, RAG 예시가 반드시 사용자 승인 데이터인지 엄격히 구분하지 않는다.
