# 실험 보고서

코드 실험과 개선 결과를 실행 순서대로 기록하는 폴더입니다.

전체 흐름과 현재 최종 상태는
[파일명 생성·적용 실험 종합 보고서](COMPREHENSIVE-REPORT.md)에서 확인할 수 있습니다.

## 작성 규칙

실제 코드 변경과 검증을 동반한 실험이 끝날 때마다 다음 규칙을 적용합니다.

1. 파일명은 `NNN-kebab-case-title.md` 형식을 사용합니다.
2. 가장 큰 기존 번호에 1을 더합니다.
3. 다음 세 영역을 반드시 독립된 제목으로 작성합니다.
   - `지난 코드의 한계`
   - `변경 코드를 통한 보완점`
   - `그러나 존재하는 한계`
4. 변경 파일, 실험 입력, 원시 출력, 최종 출력, 실행 시간, 테스트 결과를 가능한 한
   실제 측정값으로 기록합니다.
5. 실행하지 않은 검증을 성공했다고 기록하지 않습니다.
6. 실패한 실험도 삭제하지 않고 실패 원인과 다음 가설을 남깁니다.

## 새 보고서 생성

프로젝트 루트에서 다음처럼 실행합니다.

```powershell
.\scripts\new-experiment-report.ps1 -Title "실험 제목" -Slug "experiment-name"
```

스크립트가 기존 보고서 번호를 확인하고 다음 번호의 Markdown 파일을 생성합니다.
생성된 파일의 TODO를 실제 코드와 실행 결과로 채웁니다.
