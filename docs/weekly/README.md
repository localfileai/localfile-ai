# 주차별 기록

주가 끝나면 30분 안에 씁니다. 길게 쓰려고 미루면 안 쓰게 됩니다.

계획은 기획안에 있습니다. 여기 남기는 건 **실제로 무슨 일이 있었는지**입니다.
특히 계획과 어긋난 부분과 그 이유가 중요합니다. 4주 뒤에 이 기록이
"무엇을 만들었나"보다 "무엇을 알아냈나"를 설명해줍니다.

2026-07-20(월) 시작. 주는 월요일에 시작해 일요일에 끝납니다.
