[색인] 1000건 · e5-query

[A] 질의 임베딩 지연 — 커넥션 재사용 + keep_alive
    같은 질의 7회, 중위값. 첫 회는 모델 로딩이라 버린다.
    새 커넥션(종전)      :      48ms
    Session 재사용(3주차):      47ms   (중위 +1ms)
    모델 내려간 뒤 첫 질의:      47ms  <- keep_alive 10m이 없애 주는 비용

[B] RAG 컨텍스트 조회 — 질의 1번(3주차) vs 2번(예시·분류 각각)
    질의 2번(종전 설계)  :     103ms
    질의 1번(retrieve_context):      52ms   -> 추천 파일당 임베딩 비용 절반

[C] k-NN 분류 정확도 — 같은 주제 배제 (처음 보는 주제 가정, ADR-0002 §5-1)
    표본: 색인 전수 1000건 · 추가 임베딩 비용 0 (저장 벡터 재사용)
    k=1: 628/1000 = 62.8%
    k=3: 615/1000 = 61.5%
    k=5: 630/1000 = 63.0%
    (기준선 — 최빈 클래스: 17.5% · 무작위: 16.7%)
