# ADR-0002. 로컬 LLM은 exaone3.5:7.8b

- **상태**: 승인
- **날짜**: 2026-07-26
- **결정자**: BE1

## 맥락

기획안에서는 `EEVE-Korean-10.8B` 또는 `Llama-3-8B-Instruct`를 예시로 들었습니다.
실제로는 실측으로 정해야 했습니다.

제약 조건:

| | |
|---|---|
| VRAM | 8GB (RTX 3060 Ti) → 7~8B 라인 |
| 한국어 | 대상 문서가 한국어입니다 |
| JSON 출력 | Pydantic 계약을 지켜야 합니다 |
| 응답 시간 | 파일 수십 개를 순차 처리하므로 건당 시간이 누적됩니다 |

일반 사양 PC에서 돌아가지 않으면 제품 자체가 성립하지 않으므로,
10.8B는 후보에서 제외하고 7~8B 두 모델을 비교했습니다.

## 실험

합성 데이터셋 1,000건에서 표본 30건, seed 42, temperature 0.1, `format: json`.
동일 표본·동일 호출 조건으로 순차 실행했습니다.

> 실험은 반드시 하나씩 돌립니다. 동시에 돌리면 GPU 경합으로 응답 시간이
> 2배 이상 왜곡됩니다. 실제로 겪었습니다.

### A. 카테고리 분류 — 관례 미제공 (baseline)

프롬프트에 8개 카테고리 이름과 한 줄 설명만 제공.

| 모델 | 정확도 | JSON 유효율 | 평균 응답 |
|---|---|---|---|
| exaone3.5:7.8b | 20.0% (6/30) | 100.0% | 4.23s |
| qwen2.5:7b | 20.0% (6/30) | 100.0% | 4.28s |

무작위 12.5%, 최빈 클래스 15.3%보다는 높지만, **문서 유형만 읽어도 도달 가능한
72.8%에는 한참 못 미칩니다.** 두 모델 모두 본문 신호를 거의 활용하지 못했습니다.
qwen은 30건 중 23건을 `assignment`로 찍는 mode collapse를 보였습니다.

### B. 카테고리 분류 — 관례 제공

프롬프트에 폴더 관례 표를 첨부. RAG가 유사 예시로 알려줄 정보의 상한 근사치입니다.

| 모델 | 정확도 | JSON 유효율 | 평균 응답 |
|---|---|---|---|
| **exaone3.5:7.8b** | **70.0%** (21/30) | 93.3% | 4.31s |
| qwen2.5:7b | 63.3% (19/30) | 100.0% | 4.30s |

**20.0% → 70.0%.** 이 50%p가 RAG로 메울 수 있는 여지입니다.

### C. 보조 지표 — subject 10분류

본문의 `전공 분야:` 줄과 무관한 제목 중 어느 쪽을 믿는지, 즉 본문 근거 충실도.
무작위 기준선 10%.

| 모델 | 정확도 | JSON 유효율 | 평균 응답 |
|---|---|---|---|
| **exaone3.5:7.8b** | **56.7%** (17/30) | 90.0% | 3.81s |
| qwen2.5:7b | 46.7% (14/30) | 100.0% | 3.82s |

## 결정

**`exaone3.5:7.8b`를 채택하고 `qwen2.5:7b`를 fallback으로 둡니다.**

| 축 | exaone3.5:7.8b | qwen2.5:7b |
|---|---|---|
| 카테고리 (관례 제공) | **70.0%** | 63.3% |
| subject | **56.7%** | 46.7% |
| JSON 계약 준수 | 85/90 (94.4%) | **90/90 (100%)** |
| 평균 응답 | 4.31s / 3.81s | 4.30s / 3.82s |

정확도 우위(+6.7%p, +10.0%p)가 계약 위반율(5.6%)보다 큽니다.
게다가 위 정확도 지표는 **검증 실패를 이미 오답으로 세고 있으므로**,
재시도를 붙이면 격차가 더 벌어집니다.

exaone의 계약 위반 5건은 전부 형식 문제이고 파싱 실패가 아니었습니다.

- `reason` 200자 초과 3건 (`string_too_long`)
- `category`에 Enum 밖 값 2건 (`enum`)

## 결과

**필수 후속 조치**

- [ ] `ValidationError` 발생 시 위반한 제약을 프롬프트에 명시해 **1회 재시도**.
      exaone 채택의 전제 조건입니다. (`app/llm/`)
- [ ] 재시도 후에도 실패하면 해당 파일을 `failed_files`로 보고. 앱이 멈추지 않게.

**주의**

1주차 초기에 `qwen2.5:7b`를 권장한 기록이 있으나, 그 판단은 **무작위 라벨
데이터셋** 기반이라 무효입니다. 라벨 규칙을 고쳐 category가 문서 내용에서
결정되도록 만든 뒤 재측정한 위 수치가 유효한 근거입니다.

이 사건 자체가 교훈입니다. **데이터셋 라벨이 입력과 무관하면 모델 비교는
의미가 없습니다.** 정보 이득 0.0364 bit(수정 전) → 2.3817 bit(수정 후).

## 재현

```bash
cd apps/server/experiments
python generate_student_dataset.py generate --count 1000 --output ./student_dataset --overwrite

python test_models.py --sample 30 --seed 42 --explain-rule \
    --output model_test_results_with_rule.csv                     # B

python summarize_runs.py
```

## 재검토 시점

- 2주차 RAG 주입 실험 후. 유사 예시만으로 70%에 얼마나 근접하는지에 따라
  모델보다 검색 개선에 자원을 더 쓸지 판단합니다.
- 다국어 임베딩 모델 교체 후. 검색 품질이 바뀌면 이 비교의 전제가 바뀝니다.
